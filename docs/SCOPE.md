# Scope

This repository covers **Pocket Monsters Pikachu / Pokémon Yellow**.

Japanese and localized Yellow releases across independently verified revisions.

Supported releases are not inferred from names. A release becomes supported
only after its identity is recorded in `research/releases.csv` and its analysis
can be reproduced. ROM redistribution, unrelated game modifications, emulator
save data, proprietary SDKs, and unverifiable claims are out of scope.
