# Pikachu `FillMemory` disassembly

The Japanese release `pikachu-jp-rev0` is the origin reference. All 9 cataloged releases (Japanese, English, German, Spanish, French, Italian) contain exactly one ROM0 `yellow` implementation. The RGBDS source preserves the observed countdown strategy and the release maps retain identity, address, variant and code hash without publishing ROM bytes. Candidate/verified status is carried through from the existing release catalog and is not promoted by this match.
