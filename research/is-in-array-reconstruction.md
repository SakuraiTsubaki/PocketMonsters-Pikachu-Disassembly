# Pocket Monsters Pikachu IsInArray

The Japanese release `pikachu-jp-rev0` is the origin reference. All 9 cataloged releases (Japanese, English, German, French, Italian, Spanish) contain exactly one ROM0 implementation with the same nineteen-byte code hash. The secondary IsInRestOfArray entry, address, release identity and candidate status are preserved without publishing ROM bytes. English precedes the remaining official non-origin languages when no Korean release exists.
